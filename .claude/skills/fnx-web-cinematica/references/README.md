# Referencias de la skill fnx-web-cinematica

Las usa la skill `fnx-web-cinematica` (webs cinematográficas guiadas por el scroll). Leelas completas antes de diseñar, generar o construir un hero con scroll.

| Archivo | Para qué |
|---|---|
| `prompt-laws.md` | Las doce leyes del video del hero, plantillas de prompts, encadenado y consulta de costos. Leelo antes de cualquier generación. |
| `design-package.md` | La plantilla del paquete de diseño: se escribe antes de generar y se consume en la construcción. |
| `scrub-pipeline.md` | Estándar técnico del hero con scroll, legibilidad, coreografía de textos, piso de calidad y autoprueba. Incluye la adaptación FNX para celular. |
| `ffmpeg-recipes.md` | Comandos exactos de codificación, extracción, recorte y concatenación. |
| `deploy.md` | Publicación: fnxestudio.com con Lovable y webs de clientes con Vercel. |
| `troubleshooting.md` | Síntoma, causa y arreglo de problemas que ya ocurrieron. |

## Qué cambia en FNX respecto del original
- **El celular se mueve:** en vez de una imagen quieta, usa una secuencia de frames en canvas. El hero fijo queda solo para "reducir movimiento" o cuando la conexión no da.
- **Herramientas:** el generador de IA es el conector que esté disponible y siempre se dice el costo antes. El movimiento en código se hace con HyperFrames, GSAP o Remotion.
- **Publicación:** fnxestudio.com se publica con Lovable, desde una rama con vista previa y el OK de Nadin. Vercel queda para webs de clientes.
- **Identidad:** rigen la paleta y las reglas de la guía de Miro. El negro con un solo color por área es una excepción declarada al "look prohibido".
- **Honestidad:** nunca se inventan testimonios, reseñas, números ni precios, y nunca se imitan documentos oficiales.
